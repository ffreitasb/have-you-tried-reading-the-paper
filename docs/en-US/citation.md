# Cite this work

This site is the living edition of **Have You Tried Reading the Paper?**. For academic, scientific, educational or technical work, prefer the DOI of the archived version you consulted.

The project DOI collects all versions. A version DOI identifies an immutable snapshot; the web page may receive later corrections. Where that distinction matters, also include the page link and access date.

On GitHub, **Cite this repository** exports citations from `CITATION.cff`. The metadata below come from that same file on every build.
