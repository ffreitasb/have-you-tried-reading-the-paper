# Citar este trabalho

Este site é a edição viva de **Have You Tried Reading the Paper?**. Para trabalho acadêmico, científico, educacional ou técnico, prefira o DOI da versão arquivada que você consultou.

O DOI do projeto reúne todas as versões. O DOI de uma versão identifica um snapshot imutável; a página web pode receber correções posteriores. Se a distinção for relevante, inclua também o link da página e a data de acesso.

No GitHub, **Cite this repository** permite exportar a citação a partir do `CITATION.cff`. Os metadados abaixo vêm desse mesmo arquivo em cada build.
